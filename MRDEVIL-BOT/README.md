# MR DEVIL Messenger Bot

Facebook Messenger bot by **MR DEVIL**, powered by `mrdevil-fca`
(https://github.com/MRDEVIL786143/Mrdevilfca).

## Setup
1. `npm install`  (installs mrdevil-fca from GitHub)
2. Put your Facebook appstate JSON in `bot_connect/appstate.json`
3. Edit `config.json`: set `ADMINBOT` (your UID), `AI_OWNER_UID`, `BOTNAME`, `PREFIX`
4. `npm start`

Commands live in `MRDEVIL/commands`, events in `MRDEVIL/events`.
